# Contract: Asset Inventory

The authoritative machine-readable inventory is `public/assets/manifest.json`, generated by
`scripts/capture-assets.mjs`. This document defines its format and tracks the snapshot for
review (FR-012, SC-008).

## `manifest.json` format

```json
{
  "capturedAt": "2026-08-31",
  "sourceOrigin": "https://xflowresearch.com",
  "assets": [
    {
      "key": "partners/etsi",
      "localPath": "/assets/partners/etsi.webp",
      "sourceUrl": "https://xflowresearch.com/wp-content/uploads/2025/05/ETSI-Logo-300x132.webp",
      "type": "logo",
      "alt": "ETSI",
      "bytes": 0,
      "sha256": "",
      "capturedAt": "2026-08-31",
      "substitution": null
    }
  ]
}
```

## Rules

- One row per file under `public/assets/**` plus `favicon` and `og/*`.
- `key` is stable and is what content modules reference (`AssetKey`).
- `sourceUrl` is the exact origin URL, or `null` with a non-null `substitution` note when the
  asset is an openly-licensed replacement (e.g. a font, or a logo re-drawn as SVG).
- `alt` is required; `""` means decorative (rare — most items here are logos/icons that carry
  meaning).
- Every `key` referenced by `src/lib/content/**` MUST appear here (guard test).
- No `sourceUrl` may remain referenced by a rendered element — assets are copied, never hotlinked.

## Capture script contract (`scripts/capture-assets.mjs`)

- Input: `scripts/asset-sources.json` — an explicit array of `{ key, sourceUrl, type, alt }`
  compiled by hand from the three live pages.
- Behaviour: download each `sourceUrl`, write to `public/assets/<key>.<ext>`, compute `bytes`
  - `sha256`, write `public/assets/manifest.json`. Skip re-download if `sha256` unchanged.
- Dev-only: lives in `scripts/`, not imported by any `app/` or `src/` module, excluded from the
  static export. Run manually: `node scripts/capture-assets.mjs`.
- Network: the ONLY place in the repo permitted to contact `xflowresearch.com`, and only at
  authoring time.
